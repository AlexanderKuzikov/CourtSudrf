# CourtSudrf — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-07-15: Qrator блокирует go_search

**Контекст:** Эндпоинт `go_search` на sudrf.ru защищён Qrator JS-challenge.

**Решение:** Использовать только `ya_coords` (список) + `ya_info` (детали) + `go_ms_search` (мировые).

**Альтернативы:** Puppeteer для обхода Qrator.

**Trade-off:** Нет поиска по делам, только контактные данные судов.

## 2026-07-15: Rate limiting 1.5s

**Контекст:** 2334 суда × 1 запрос `ya_info` каждый.

**Решение:** Bottleneck с minTime 1500ms (~58 минут полный прогон).

**Альтернативы:** Быстрее — риск бана.

**Trade-off:** Долгий прогон, но надёжность.

## 2026-07-15: Формат совместим с CourtHarvest2

**Контекст:** Данные CourtSudrf должны дополнять CourtHarvest2.

**Решение:** Одинаковая структура CourtRecord, коды RRTTNNNN.

**Альтернативы:** Свой формат.

**Trade-off:** Ограничения CH2 по полям, но 98% overlap по кодам.
